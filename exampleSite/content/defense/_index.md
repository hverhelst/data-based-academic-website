A standalone page, of the kind that is worth having a URL but not a place in
the navigation — a defense announcement, a workshop page, a set of photographs
you want to hand someone a link to.

It is a page bundle: the images sit next to this file rather than in `static/`,
which is what lets the `imgresize` shortcode resize them. Nothing here is
registered in `data/sections.json`, so the section navigation never links it.
Reaching it means knowing the address.
